## Experience and projects

### Pix — full-stack developer

From September 2020 to October 2023, I worked on the content and access teams, each with five to six people. My contributions included:

- Redesigning access to educational content, reducing network calls sixfold.
- Developing interactive educational simulators configurable by business teams.
- Deploying an SSO solution for a regional education authority and developing a GDPR-compliant logging application.
- Contributing to the internal design system and a major back-office migration.

Main technologies: Ember.js, TypeScript, Vue.js, and Hapi.js.

### MusicKeeper — independent project

Since October 2024, I have designed and developed [MusicKeeper](https://musickeeper.app) solo: an open-source app for managing music recommendations. I own the product end to end, from defining the need to deployment.

The project uses Svelte, TypeScript, AdonisJS, and Docker. It includes hexagonal architecture, unit, functional and end-to-end tests, CI/CD, and an offline-capable PWA.

- App: https://musickeeper.app
- Source: https://github.com/Thomasevano/musickeeper

### EasyDocker — team project

EasyDocker is a final-year project built by a team of five: an interface for creating and managing Docker Compose files. I worked on frontend stack CRUD and YAML editing, migration to Vite and Vitest, and backend networking, a database service, integration tests, and CI.

- Source: https://github.com/Thomasevano/EasyDocker
